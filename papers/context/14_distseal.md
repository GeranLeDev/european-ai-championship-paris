# CONTEXTE AGENT — DistSeal : Learning to Watermark in the Latent Space of Generative Models (Meta FAIR, arXiv 2601.16140, janv. 2026)
Source vérifiée : texte complet lu (corps + annexes A-I ; la « Section 6.3 » citée dans la conclusion pour la suppression de watermark n'existe pas dans le texte fourni). Code + modèles : github.com/facebookresearch/distseal · Pierre Fernandez = co-auteur.

## En une phrase
Un watermarker **post-hoc entraîné dans l'espace latent** (embedder + extracteur) du générateur, puis **distillé** soit dans le modèle génératif (diffusion ou autorégressif), soit dans le décodeur latent → watermark in-model, sans surcoût d'inférence, applicable aux modèles open-source. Jusqu'à **20× plus rapide** que le pixel-space et la distillation du latent marche mieux que celle du pixel.

## Méthode & formules
- **Embedder latent** : `zw = z + ε·Wθ(z, m)`, `xw = D(zw)`, message K bits (64). Pixel : `xw = x + ε·Wθ(x,m)`. Architecture VideoSeal sans les couches down/up-sampling (U-Net → blocs ResNet centraux), extracteur ConvNeXt-tiny inchangé. Entrainé avec augmentations (valuemetric, géométriques, compression).
- **Autorégressif (tokens discrets)** : embedder appliqué **avant** quantif `zw = Q(z + ε·Wθ(z,m))` (straight-through) ou **après** (sur les embeddings de tokens).
- **Loss post-hoc** : `L = λw·Lw(xw,m) + λdisc·Ldisc(x,xw)` (λw=1.0, λdisc=0.1, discriminateur pixel actif après 200k pas) ; **aucune loss de reconstruction/perceptuelle** (elles gênent car des perturbations latentes peuvent changer le sémantique) : seulement ε + discriminateur. « Coverless » (sans dépendre de l'image) testé : moins robuste.
- **Distillation dans le modèle génératif** : on watermarke les latents d'entraînement avec message fixe m et on fine-tune : `Lgen = Lrecon(Gφ(x), zw)` (MSE diffusion, cross-entropy AR). Plug-and-play, aucun hyperparamètre.
- **Distillation dans le décodeur** : `Ldist = Lrec(Do(zw), D(z)) + λw·Lw(Eθ(D(z)), m)`, `Lrec = ℓ1 + λp·LPIPS`. Différence avec Stable Signature : le décodeur **reconstruit l'image watermarquée** de l'embedder (SS n'utilise que le signal de l'extracteur).
- Pixel-space et latent entraînés à l'identique (600k pas, ImageNet, batch 128, lr 5e-4, schedule ε fort 100k pas puis cosine sur 100k pas) : DCAE ε 1.5→0.5 ; RAR après quantif 2.0→0.5, avant 3.0→1.5 ; pixel 0.2→0.02. Distillation diffusion : 100k pas ; AR : 10k pas (~50 GPU-h) ; décodeur : 10k pas, batch 16, lr 1e-4.
- Modèles : diffusion = DC-AE UViT-H ImageNet (latents 8×8×128 → 512×512) ; AR = RAR-XL (MaskGIT-VQGAN, 256 tokens, codebook 1024, images 256×256) ; MaskBit en annexe G. 50k images pour les métriques.

## Résultats clés (bit accuracy %, moyenne sur transformations ; « Combiné » = JPEG + crop 0.71 + brightness 0.5)
- **Post-hoc DC-AE (Table 1)** : pixel avg 97.78 (combiné 97.29, PSNR 43.48, FID 10.84) ; **latent avg 95.18** (combiné 84.28, PSNR 31.06, FID 11.42) ; coverless 91.81. FID de référence 10.66. Le PSNR bas est « trompeur » selon les auteurs.
- **Vitesse** : DC-AE 3 ms vs 63 ms/image CPU (**20×**) ; RAR 17 ms vs 41 ms (**2.4×**, latent moins compressé).
- **Post-hoc RAR (Table 2)** : pixel 97.27 ; latent après quantif 93.96 (PSNR 24.54, FID 3.44) ; avant quantif 90.60. Seul « avant quantif » est distillable dans le transformeur AR (il produit une nouvelle séquence de tokens).
- **Distillation décodeur (DC-AE, Table 3)** : latent → 94.41 avg avec λw=0, **96.77 avec λw=0.1 (mieux que le teacher 95.18)**, FID 11.48. **Pixel → échec : 51.38 % (λw=0), 89.16 (λw=0.1), 92.95 (λw=1.0 mais FID 17.08).** Explication : les perturbations haute fréquence du pixel sont dures à reproduire pour le décodeur. RAR : latent 81.40 / 90.57 (λw=0.1) / 92.33 (λw=0.5) ; pixel 50.15 / 50.81 / 71.25 (FID 5.05). Les autres post-hoc (CIN, MBRS, TrustMark, WAM) : distillation du décodeur RAR quasi impossible sauf WAM.
- **Distillation modèle génératif (Table 5)** : DC-AE 94.78 vs teacher 95.18 (FID 10.90 vs 11.42) ; RAR 89.13 vs 90.60 (FID 3.32 vs 3.56). Modèle génératif : un peu moins robuste mais meilleur FID que le décodeur distillé.
- **vs Stable Signature (Table 10, même teacher, DC-AE)** : combiné 73.24 (λw=0.1) / 77.65 (0.5) pour SS contre 82.58 (λw=0) / 91.34 (0.1) pour DistSeal ; un λw trop fort sur-apprend « Identity » et dégrade la robustesse.
- **Formation du watermark** : la bit accuracy monte au fil des pas de diffusion ; reste élevée même si le modèle distillé n'est utilisé que sur les derniers pas ; AR : bit acc 0.80 avec seulement la moitié des tokens générés par le modèle distillé ; DistSeal change les tokens bien plus que WMAR (KGW).
- **Multi-watermarking (annexe F)** : RAR distillé + post-hoc (CIN/MBRS/TrustMark/WAM) ou WMAR : perte < 1 point (décodeur : ~1-1.7) ; **DC-AE distillé : −7 à −8 points en moyenne, ~−20 en combiné.**
- **Oubli par LoRA (annexe E)** : fine-tuning LoRA de 2500 pas sur 50 images non marquées : lr 1e-5 → bit acc 0.82 (diffusion) / 0.76 (AR) ; lr 1e-4 → 0.70 / 0.65 (le texte écrit « % » par erreur, ce sont des fractions). Le décodeur distillé n'est pas affecté par un fine-tuning du générateur.
- **Choix (Table 6)** : modèle génératif = plug-and-play, meilleur FID, robuste au fine-tuning du décodeur mais **sensible à l'oubli LoRA** ; décodeur = robuste à l'oubli LoRA du générateur mais **vulnérable au remplacement du décodeur**, λw/λp à régler, risque de flou (λp=0 sur RAR). Un décodeur RAR fine-tuné cycle-consistent (WMAR) fait même monter la bit acc (annexe H.1).

## Limites & angles hackathon
- Le watermark peut toujours être supprimé (de l'aveu des auteurs) ; robustesse insuffisante contre certaines **transformations géométriques fortes** (piste : synchronisation post-hoc, Fernandez et al. 2025) ; combiné moins bon que le pixel (84 vs 97 sur DC-AE, 77-82 sur RAR).
- La distillation est **bornée par le watermarker post-hoc** ; pour l'AR, **bornée par le nombre de tokens discrets** (quantif efface les petites perturbations). Message fixe (pas de message par utilisateur sans nouvelle distillation). Expériences ImageNet class-conditional seulement (inférence : généralisation au text-to-image non montrée ici).
- Angles défi : remplacer le décodeur, LoRA/fine-tuning sur images non marquées, attaques combinées (JPEG+crop+luminosité), pipeline double-watermark. Message 64 bits → p-value binomiale comme dans Stable Signature (inférence : formule non redonnée dans ce texte).
